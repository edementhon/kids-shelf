Add a folder or NAS share

Each folder inside the folder you add becomes a show on the shelf, named after that folder. Videos placed straight in the folder you add go into one show named after it. NAS = a network drive, like a Synology or a Plex box.

Where do I find the path?
  • Windows: a folder like D:\Videos\Kids; a NAS share is at \\SERVER\Kids. In File Explorer, right-click the folder and choose "Copy as path".
  • Mac: a folder like /Users/you/Movies/Kids; a NAS share appears under /Volumes/.
  • Linux: a folder like /home/you/Videos/Kids; a NAS share is usually mounted at /mnt/ or /media/.

A good layout: Kids/Bluey/episode 1.mp4, Kids/Peppa Pig/episode 1.mp4. Add the Kids folder and you get two shows.

Tip: connect the NAS first so this computer can see it, then paste its address here. Choosing "A network drive (NAS)" makes the list tell you to check the NAS when it can't be reached.

Conversions

Videos are turned into a format every browser can play. This list shows the work waiting and running, and what finished in the last day. A video that could not be added can be tried again.

Fixing videos

Some videos cannot play well yet, so kids-shelf makes them a better copy in the background. This card lists the ones still waiting and the ones it could not fix.

Offline libraries

Once downloaded, libraries work with no internet (great for trips). Think about space before you download: all of English Wikipedia needs about 120 GB. Wikipedia's top 100 articles: 318 MB. The kids' encyclopedia Vikidia is 74 MB.

Library files on this computer

Already have library files (.zim)? kids-shelf can use them where they are, without copying them.
